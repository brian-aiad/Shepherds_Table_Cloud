# Project structure

## Purpose

Preserve the existing Shepherds Table Cloud application and its independent source history.

## Canonical workspace

Windows: %USERPROFILE%\Desktop\Projects\OLD_Projects\ShepherdsTableCloud\shepherds-table-cloud. Mac: ~/Code/Projects/OLD_Projects/ShepherdsTableCloud/shepherds-table-cloud. Repository: brian-aiad/Shepherds_Table_Cloud, main.

## Folder map

src/ contains React application pages, authentication, components and document utilities. public/ contains public site assets and blank forms. Firebase configuration and rules remain in their established root locations. The parent folder's operational exports and records are outside this repository's publication scope. dist and dist 2 are generated local build output.

## Commands

npm run build performs the existing TypeScript and Vite production build. Inspect git status and git diff --check before publishing. Deployment and migration scripts affect external systems and are not organization checks.
